* **DECIDED** — confirmed by the user or already fixed by project policy.
* **ASSUMPTION** — recorded because the task does not fully specify the choice; revisit when the referenced engine work starts.

| 34 | ASSUMPTION | Login throttling | Five failed attempts for one email within fifteen minutes return HTTP 429. | 38 | ASSUMPTION | JSON strictness | Unknown request properties are rejected with HTTP 400 for every endpoint, not only registration. | The task explicitly named `phone`/`role` on registration; applying the same Boot/Jackson setting globally is simpler, safer and tested through the admin endpoint too. |
| 39 | ASSUMPTION | Project status | Publishing maps `DRAFT` to `PUBLISHED`; publishing an already published project is idempotent; any later status returns 409. Retaining a future engine's status avoids moving a formed project backwards, and idempotent publish/lock makes retries safe. |
| 40 | ASSUMPTION | Preference lock | `ProjectService.arePreferencesLocked` is the single lock check for update, roster and preference operations. | 41 | ASSUMPTION | Deadline precision | Deadline and lock timestamps are second-precision `TIMESTAMP` columns.
